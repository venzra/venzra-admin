Overview

A payment gateway is required to enable customers to start using your store to place orders.

We use Stripe as a gateway for payments, to setup this gateway and start taking orders and recieving payments for orders please use the link below. If you would like more information about Stripe please visit their website at https://www.stripe.com.

To process payments on your store every transaction is charged at 6% of the order value plus a 30p base charge (inclusive of any gateway fees). For example an order of £20 would incur a fee of £1.50 for processing.

Transaction fees can be reduced by setting up a monthly subscription after you have added your gateway. With an active and paid subscription the transaction fee is reduced to 3.5%, this would mean a £20 order would incur a fee of £1 saving 50p compared with a non-subscription based transaction. Note that fees can vary when customers use international cards by up to 1.5%, refer to Stripe pricing for more information.
