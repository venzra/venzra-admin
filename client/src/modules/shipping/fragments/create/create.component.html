Shipping options can be configured to only appear when the customers cart qualifies to use the option. However you should ensure that you will always have the ability to provide a shipping option to a customer.
Displayed information The following details setup a shipping option to be shown during checkout, it can be configured to only display the option based on the customers cart value. Option thresholds Control when this option will be made available to customers, for example when a customer has a cart with a value of £50 you may want to offer free two day delivery, and then when the car reaches £100 they could have free next day delivery as an option. Typically maximum should be equal or greater than the minimum set, unless no maximum applies. £   Minimum cart spend that triggers showing this option. Leave as zero if no minimum spend. Fulfilment expectations This is how long you would expect to normally fulfil the delivery based on the option that has been chosen. Currently this is only used as an internal tool to allow ordering customer orders based on when you expect them to be completed. Not shown to customers, this is used to help prioritise your order fulfilment based on expected delivery. This field is required. Must contain a positive number. Entered value is too large.
